# عقدي — النسخة القابلة للتثبيت (PWA)

## المحتويات
- `index.html` — التطبيق كاملًا (يعمل بدون إنترنت)
- `manifest.webmanifest` — بيانات التثبيت (الاسم، الأيقونة، وضع ملء الشاشة)
- `sw.js` — Service Worker للتخزين المؤقت والعمل بدون إنترنت
- `icons/` — أيقونات التطبيق (192 و512 وmaskable وأيقونة آيفون)

## التثبيت على الموبايل
1. ارفع محتويات هذا المجلد كما هي على أي استضافة HTTPS ثابتة (GitHub Pages، Netlify، Cloudflare Pages...).
2. افتح الرابط في متصفح كروم على الموبايل.
3. من قائمة المتصفح (⋮) اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4. ستظهر أيقونة «عقدي» على الشاشة، ويفتح التطبيق في نافذة مستقلة بملء الشاشة ويعمل بدون إنترنت.

## ملاحظات
- التثبيت كتطبيق مستقل يتطلب رابط HTTPS. فتح `index.html` مباشرة من الجهاز يعمل، لكن بدون أيقونة مستقلة.
- المسودات وبياناتك تُحفظ على جهازك فقط (localStorage)، ولا تُرسل لأي خادم.
